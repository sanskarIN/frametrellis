# FrameTrellis 1.4.0 early-access candidate — desktop verification checklist

This is a **testing checklist**, not an assertion that testing passed.
Record the release SHA, OS, install/build type, Qt/MLT/FFmpeg versions,
manual result and any output files before promoting a release to stable.

Use disposable media copies, temporary output paths and copied `.ftproj`
projects. Never use irreplaceable source material for compatibility tests.

## Integration and package gates

- [ ] Same-SHA main branch Linux GCC CI passes: compile, unit, GUI,
      integration tests and clang-tidy.
- [ ] Same-SHA sanitizer and Windows MSYS2 CI pass.
- [ ] Same-SHA Windows packaging verifies installer and ZIP on Server 2022,
      Server 2025 and Windows 11 ARM64 x64 emulation.
- [ ] Release workflow produces checksum, SPDX SBOM and corresponding
      bundled third-party source archives; no partial packages published.
- [ ] Published tag is marked a **prerelease**, not the latest stable release.
- [ ] A fresh launch of the package shows the correct build version.

## Markers and project compatibility

- [ ] Open a v1 project created by FrameTrellis 1.3.0 on a throwaway copy.
- [ ] Add frame-zero marker and two later markers through QML, then rename,
      move and delete markers; confirm undo/redo each operation.
- [ ] Verify ruler diamonds, clicking to seek, previous/next shortcuts
      and optional clip snapping at marker frames.
- [ ] Save as a new `.ftproj`, restart and confirm markers and labels survive
      round trip, including Unicode labels and fractional frame rates.
- [ ] Confirm v1.3.0 explicitly rejects the copied v2 project without
      modifying it. Keep the original v1 fixture intact.
- [ ] Shorten a sequence so that a marker lies beyond the new end; no crash,
      invalid transport position or lost marker.

## Chapters, WebVTT and interchange

- [ ] Copy video-description chapters: first cue at frame zero, times
      nondecreasing by whole seconds, Unicode text preserved.
- [ ] Reject a missing frame-zero chapter and duplicate whole-second starts,
      preserving clipboard content and the current edit.
- [ ] Copy WebVTT chapters: valid `WEBVTT` heading, increasing cue intervals,
      escaped markup, frame-derived end at the sequence boundary.
- [ ] Import the `.vtt` into a compatible HTML5 player as a chapter track.
- [ ] Copy picture EDL for one visible video track with cuts, gaps and
      reused source files. Inspect eight-character reel fields, source
      in/out and record in/out, and the `BL` gap event.
- [ ] Import/conform the EDL in a compatible editor and verify correct
      source selection and edit boundaries. Check a 29.97 drop-frame case.
- [ ] Attempt a layered timeline, dissolve, still clip, mismatched source
      rate and modified picture: EDL must fail clearly rather than omit effects.
- [ ] Check neither clipboard export modifies the project or its undo history.

## Slip edit, picture and sound

- [ ] Select one video clip with source handles. Slip earlier and later by one
      and ten source frames. Timeline position/duration remain unchanged.
- [ ] Select clips across video and audio tracks. Slip together; check
      properties, undo and redo preserve all source/record values.
- [ ] Try clips at source boundary, locked tracks, still images and a
      transition requiring handle frames. Failed slips must leave all clips
      and the undo stack unchanged.
- [ ] Confirm source changes appear in preview and match exported video/audio.
- [ ] Retest existing trim, split, duplication, snapping, fading,
      crossfades, titles, export and playback at representative rates.
