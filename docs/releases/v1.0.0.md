# FrameTrellis 1.0.0

The first stable release of FrameTrellis: a local-first, open-source desktop video editor for
precise, multi-track editing. There is no account, no cloud processing, no telemetry and no
advertising. Everything runs on your computer.

## Highlights

- **Multi-track timeline.** Video and audio tracks with move (also between tracks), trim, split,
  delete and ripple delete. Clips snap to edges and the playhead, and an edit that would overlap
  another clip is refused, never applied destructively.
- **Transitions.** A dissolve for the picture and a crossfade for the sound, centred on the cut
  between two touching clips, with an adjustable length.
- **Real waveforms.** Clips on audio tracks show the waveform of their actual sound. It is
  computed once per file in the background and cached.
- **Real-time preview** with synchronised audio, frame stepping, edit-point navigation and
  frame-accurate timecode (including drop-frame).
- **Clip adjustments.** Volume, mute, fades, opacity, brightness, contrast and saturation.
- **MP4 export** (H.264 + AAC) with presets, quality and speed settings. Exports run in a separate
  process with progress and cancel, and each file is verified before it is kept.
- **Safe projects.** A versioned, validated JSON project format (`.ftproj`) with atomic saves,
  undo/redo (500 steps), autosave every minute, crash recovery and missing-media relinking.
- **Windows packages.** An installer and a portable ZIP that bundle everything the editor needs,
  with the license texts of every bundled component, a software bill of materials (SPDX 2.3) and
  an archive with the source code of the bundled components.
- **Installation self-test.** `frametrellis-render --self-test <folder>` checks the media engine,
  writes sample media, builds a project, exports it and verifies the result. When a part of the
  media engine cannot be loaded, it says which one and why.

## Supported platforms

| Platform | Status in 1.0.0 |
|---|---|
| Windows 11 and Windows 10 (version 1809 or later), x64 | Installer and portable ZIP. Both are verified automatically on clean Windows Server 2022, Windows Server 2025 and Windows 11 (ARM64, x64 emulation) machines before publication. |
| Linux (x86-64) | Build from source. Tested in CI on Ubuntu 24.04. No package yet. |
| macOS | Not supported yet. |

## Installing

Download the installer or the ZIP below and follow the
[installation guide](https://sanskarin.github.io/frametrellis/docs/installation/). The packages
are not code-signed, so Windows SmartScreen may ask for confirmation: check the SHA-256 checksum
first. To check an installation, run `frametrellis-render.exe --self-test <folder>` from the
program folder. It edits and exports sample media and reports each step.

## Supported formats

- **Import:** video, audio and images that the bundled FFmpeg and Qt can decode, for example
  MP4, MOV, MKV, WebM, AVI, MTS and MXF video (H.264, HEVC, VP9, AV1, ProRes, DNxHD and more),
  WAV, MP3, AAC, FLAC, Ogg, Opus and AIFF audio, and PNG, JPEG, BMP, GIF, TIFF and WebP images.
- **Export:** MP4 with H.264 video and AAC audio, at the project's size or scaled to 720p, 1080p
  or 2160p.
- **Projects:** `.ftproj` (JSON, format version 1).

The details are in [Supported formats](https://sanskarin.github.io/frametrellis/docs/formats/).

## Known limitations

- MP4 (H.264 + AAC) is the only export format.
- Dissolve/crossfade is the only transition. There are no titles, keyframes or subtitles yet.
- The project frame rate can only be changed while the timeline is empty.
- Very long timelines (thousands of clips) have not been optimised yet.
- Exports render frames one at a time, because MLT's parallel rendering produced corrupt audio on
  some versions. Exports are correct but not as fast as they could be.
- The Windows packages are not code-signed. Automatic checks run on clean virtual machines, not
  on physical Windows 11 PCs. Please report any problem you find.
- There are no packages for Linux or macOS yet.
