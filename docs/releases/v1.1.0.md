# FrameTrellis 1.1.0

FrameTrellis 1.1.0 adds faster timeline editing and basic title creation to the local-first,
open-source desktop video editor. It builds on 1.0.0 without changing the project file format.
Projects and source footage stay on your computer: no accounts, uploads or telemetry.

## What's new

- **Duplicate a clip.** Select one clip and press **Ctrl+D**, use **Edit → Duplicate Clip**,
  or choose the duplicate action on the timeline toolbar. The new clip is appended after the
  existing clips on the same unlocked track without overwriting anything. It keeps the same
  source in/out trim, duration and clip adjustments. Transitions are not duplicated. The
  duplication is one undoable edit (**Ctrl+Z**).
- **Create title overlays.** Use **File → Create Title…** to draw text as a transparent PNG
  with a chosen font size and colour. Save the project first: the new PNG is stored in the
  `FrameTrellis Titles` folder beside the `.ftproj` project, imported into the media bin
  and placed at the end of the highest unlocked video track. Move it above your footage,
  position it in time and trim its duration just like any still image.
- **Headless container renderer.** The container image
  `ghcr.io/sanskarin/frametrellis-render` provides a way to render compatible FrameTrellis
  projects in CI or on a server; see the
  [container guide](https://github.com/sanskarIN/frametrellis/blob/v1.1.0/docs/user-guide/container.md).
  It is a separate distribution path from the desktop application.

## Quality and testing

- Linux GCC/debug builds run with warnings treated as errors; the full CTest suite, GUI
  interaction tests, and `clang-tidy` static analysis are checked in GitHub Actions.
- AddressSanitizer and UndefinedBehaviorSanitizer run on Linux unit/integration tests.
- Windows MSYS2 builds and tests run in CI.
- Windows x64 portable and installer builds undergo clean-machine verification on
  Windows Server 2022, Windows Server 2025 and Windows 11 ARM64 (x64 emulation).
- GUI tests cover title PNG creation, project save/reopen and clip duplication. An engine
  integration test verifies that transparent image pixels reveal footage on lower tracks.
- Release packaging includes checksum manifests, bundled-component licensing information,
  an SPDX bill of materials and corresponding third-party sources.

## Installing or upgrading

Get the Windows installer or portable ZIP in the assets attached below. Existing 1.0.0
projects open in 1.1.0; save a copy of important projects before upgrading.

The Windows packages are **not digitally signed**. Verify `SHA256SUMS.txt` before running an
installer. The built-in `frametrellis-render.exe --self-test <folder>` checks that the media
engine can decode, render and export a sample project.

For setup details, see the
[installation guide](https://github.com/sanskarIN/frametrellis/blob/v1.1.0/docs/user-guide/installation.md).

## Known limitations

- Title overlays are **raster images**, not editable text layers. To change wording or style,
  create a new title image. Text size and colour can be chosen during creation; there is no
  title keyframe animation or direct text editing on the timeline.
- Generated title PNGs are separate media files. Keep the `FrameTrellis Titles` folder
  together with your project when moving or sharing it. After **Save As** to another folder,
  the project can still reference the original title images; copy them too or use relinking.
- A title is appended on the highest **unlocked** video track; if a higher video track is
  locked, adjust track order or unlock it to place the title above all footage.
- Only H.264/AAC MP4 output is supported. A dissolve/crossfade is the only transition type.
  Keyframes, subtitles and proxy-media workflows are not included.
- Exports render frames serially; large timelines and demanding footage have not yet been
  optimised. Linux/macOS packages and Windows code signing remain future work.
- CI uses virtual or headless environments; hardware-specific issues on physical PCs may
  still occur. Please [report bugs](https://github.com/sanskarIN/frametrellis/issues).
