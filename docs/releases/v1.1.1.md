# FrameTrellis 1.1.1

FrameTrellis 1.1.1 is a maintenance update focused on making title creation more predictable
and expanding export regression coverage. It preserves the features and project file format
introduced in 1.1.0.

## Fixed

- **Title creation on locked tracks.** The Create Title dialog now checks whether at least
  one unlocked video track is available before enabling **Create title**. When all video
  tracks are locked, it explains that one must be unlocked or added. This prevents the
  normal dialog workflow from producing an imported but unplaced title PNG.
- **Title insertion feedback.** The dialog closes only when a generated title is
  successfully added to the timeline. If placement is refused, the dialog remains open,
  rather than implying success.

## Tests and validation

- Added GUI regression coverage for locking all video tracks, disabling title creation,
  unlocking a track and re-enabling the dialog action without restarting the editor.
- Added an end-to-end export regression test that places a transparent title-style PNG
  above video, exports an MP4 and checks that opaque overlay pixels and the underlying
  video are both visible in the decoded output.
- The normal project, timeline, render, GUI, Windows packaging and installation smoke tests
  continue to run in CI before a public release is published.

## Compatibility

- Projects saved in 1.0.0 and 1.1.0 continue using the same `.ftproj` format (version 1).
- **Windows 10 (1809 or later) and Windows 11, x64:** installer and portable ZIP.
- **Linux x86-64:** build from source; tested on Ubuntu 24.04.
- **macOS:** not supported in this release.

## Known limitations

- Titles are generated PNG files, not editable text layers. Keep the
  `FrameTrellis Titles` directory with the project when moving or sharing it.
  If you save a project to a different folder, title files are not automatically copied.
- A title is appended at the end of the uppermost unlocked video track; it may need to be
  dragged to its intended point in the edit.
- MP4 (H.264/AAC) remains the supported export format. Keyframes, subtitles, native
  editable title layers and proxy media are still planned.
- There are no ready-to-install Linux or macOS packages yet. Windows packages are not
  code-signed; verify their published SHA-256 checksums before running them.
- Builds are tested on CI and clean virtual Windows environments, not every physical
  graphics/audio configuration.

## Installing

Download the installer or portable ZIP attached to this release. To confirm a package
is complete, compare it with `SHA256SUMS.txt`. Existing projects should open unchanged;
as with any editing software, keep backups of important projects.

See the [installation guide](https://github.com/sanskarIN/frametrellis/blob/v1.1.1/docs/user-guide/installation.md),
the [user guide](https://github.com/sanskarIN/frametrellis/blob/v1.1.1/docs/user-guide/README.md),
and [issue tracker](https://github.com/sanskarIN/frametrellis/issues).
