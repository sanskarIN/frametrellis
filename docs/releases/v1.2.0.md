# FrameTrellis 1.2.0 — Batch timeline editing

FrameTrellis 1.2.0 expands the C++ timeline editing workflow with non-destructive,
multi-clip operations that reduce repetitive work while preserving undo and project
compatibility. Built with C++20, Qt 6/QML, MLT and FFmpeg. Footage remains local.

## New features

### Multi-clip duplication
- Select several clips (including clips across video and audio tracks), then press **Ctrl+D**.
- The group is duplicated after the entire timeline, preserving the relative spacing
  and sync between selected clips, and keeping each copy on its original track.
- Each copy keeps its media source, source in-point, duration, volume, fade, mute and
  picture adjustments. Original transitions are not copied.
- Single-clip Ctrl+D retains its familiar append-to-current-track behaviour.
- A group is duplicated as one atomic, undoable edit. Locked tracks and invalid
  destinations reject the entire operation.

### Clip attribute clipboard
- **Ctrl+Alt+C** copies a selected clip's audio volume, mute, fades, brightness,
  contrast, saturation and opacity.
- **Ctrl+Alt+V** pastes those attributes to one or more selected destination clips
  as one undoable operation. Fades are shortened when a destination clip is shorter.
- Only the adjustments are copied. The source media, clip timing, clip duration
  and transitions are not modified.

### Batch mute and picture reset
- **Ctrl+Alt+M** / **Ctrl+Alt+U** mute/unmute the audio of all selected clips.
- **Edit → Reset Selected Picture Adjustments** restores default picture attributes
  across a selection, preserving the existing audio volume, mute and fades.
- Every batch action is atomic: locked or invalid selections never result in
  partially modified tracks.

### Frame-accurate group nudging
- Nudge selected clips together by one frame using **Alt+Left / Alt+Right**, or ten frames using **Alt+Shift+Left / Alt+Shift+Right**.
- Movement preserves cross-track synchronization, clip attributes, and valid transitions. Locked tracks, collisions and invalid bounds refuse the whole operation without changing undo history.

### Interface and documentation
- Added the new commands to the **Edit** menu, keyboard shortcut reference and
  help dialog.
- Added a [batch editing guide](https://github.com/sanskarIN/frametrellis/blob/v1.2.0/docs/user-guide/batch-editing.md).
- Expanded unit and GUI regression coverage for multi-track duplication, clipboard
  paste, atomic rollback, undo/redo, fade clamping and keyboard shortcuts.

## Compatibility and downloads

- **Windows 10 (1809 or later) and Windows 11, x64:** installer (.exe) and portable (.zip).
- **Linux:** build from source; CI covers an Ubuntu 24.04 environment.
- **macOS:** not yet supported. No macOS or Linux prebuilt installers are claimed.
- The existing `.ftproj` version 1 format is unchanged. Projects from 1.0.0 and
  1.1.x remain compatible.

## Known limitations

- Multi-clip duplication copies clips, not the transitions linking them.
- The attribute clipboard is internal to the running editor, not the system clipboard.
- The pasted fade lengths are adapted to the destination clip length; the clip's
  duration and trims are never changed by pasting attributes.
- Titles are PNG assets, not editable text layers; keep the `FrameTrellis Titles`
  folder with its project. Saving a copy of a project elsewhere does not copy title files.
- Only MP4 (H.264/AAC) is supported for export. Proxies, keyframes, subtitles and more
  export formats remain future work.
- Windows packages are not code-signed; compare downloaded files with the
  attached SHA-256 checksum manifest.
- Automated tests cannot cover every physical GPU and audio hardware combination.
