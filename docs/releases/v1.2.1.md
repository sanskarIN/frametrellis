# FrameTrellis 1.2.1 — Startup diagnostics and Windows package verification

FrameTrellis 1.2.1 is a **stable maintenance update** to the local-first C++20/Qt
desktop video editor. It preserves project-format compatibility with the 1.2.0,
1.1.x and 1.0.0 releases. No WinGet integration is included in this update.

## Improvements

- **Reliable cleanup if QML window initialization fails.** Startup no longer
  exits before application controllers, background worker tasks and the MLT
  runtime have followed the usual shutdown path.
- **Clearer startup diagnostics.** Editor logs include startup, QML window
  creation, event-loop shutdown and final cleanup checkpoints.
- **Stronger Windows package verification.** Editor stdout/stderr and available
  application crash logs are collected as GitHub Actions artifacts.
- **Independent ARM64-emulation launches.** Windows 11 ARM64 now verifies the
  portable x64 editor twice, requiring both runs to finish successfully and
  produce fresh screenshots. Passing a later run cannot conceal an earlier
  failure.
- **Strict DLL-path checking.** Module inspection rejects sibling directories
  that merely share an allowed path prefix and paths escaping allowed
  directories through traversal. Failed module inspection and premature editor
  exits are test failures, not silent skips.
- **Fresh screenshots and test logs.** Previous verification artifacts are
  cleared before each editor launch.
- **Regression tests.** Added a dedicated Windows PowerShell suite for module
  path handling and integrated it into the package workflow.

## Validation

On the final pre-release maintenance branch, GitHub Actions completed:

- Linux GCC debug builds and unit, integration and GUI tests.
- Linux AddressSanitizer/UndefinedBehaviorSanitizer tests.
- Windows MSYS2 UCRT64 compilation and tests.
- Code formatting and packaging script tests.
- Windows installer and portable verification on Windows Server 2022,
  Windows Server 2025 and Windows 11 ARM64 (x64 emulation).
- Website and container-image workflows.

The release workflow separately rebuilds, tests and checks the final
version-stamped Windows packages before publishing them.

## Known limitations

A v1.2.0 post-release check once observed an intermittent portable x64 GUI
startup access violation within Qt6Core.dll on a Windows 11 ARM64 runner. A
subsequent retry and the v1.2.1 pre-release checks passed. **The underlying
cause has not been established, so this release does not claim a confirmed
fix for that incident.** The added diagnostics and stricter checks improve
investigation and failure detection. Physical ARM64 hardware and all possible
GPU/audio driver configurations have not been exhaustively tested.

The Windows packages remain unsigned. Compare the SHA-256 checksum file
provided with the release before installing. No Linux or macOS prebuilt
packages are supplied; Linux users can build from source. Export is currently
MP4/H.264/AAC, and titles are raster PNG overlays. See the
[installation guide](https://github.com/sanskarIN/frametrellis/blob/v1.2.1/docs/user-guide/installation.md)
and [testing documentation](https://github.com/sanskarIN/frametrellis/blob/v1.2.1/docs/testing.md).

## Compatibility and future work

The existing `.ftproj` format remains unchanged. Installer and portable ZIP
assets target Windows 10 (1809 or later) and Windows 11, x64, including x64
emulation on compatible ARM64 systems. WinGet packaging and updates are
planned separately for a possible **v1.2.2**, not this release.

FrameTrellis is available under the GPL-3.0-or-later license. Release assets
include checksums, an SPDX bill of materials and bundled component sources.
