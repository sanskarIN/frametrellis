# FrameTrellis 1.2.2 — Faster export profiles

FrameTrellis 1.2.2 expands export controls with convenient quick H.264
profiles and an explicit way to avoid unnecessary upscaling.

## Changes
- Quick project-resolution export: veryfast H.264 at CRF 22.
- Quick up-to-1080p export: speed-optimized with no needless upscaling.
- Turbo up-to-720p preview: superfast H.264 for rapid reviews.
- Existing fast draft preset avoids automatically magnifying small projects.
- Optional no-upscale checkbox in Export settings and --no-upscale in the
  separate render helper CLI.
- Live average frames/second beside export progress and ETA.
- Unit and end-to-end regression tests for preset policies, dimensions, AAC
  retention and helper-process flag propagation.

## Compatibility and cautions

MLT parallel frame rendering remains disabled due to known prior AAC
corruption. Encoding still uses normal encoder threads. Real export times
vary by effects, hardware, resolution and input formats. These features do
not implement stream-copy joining or guarantee GPU acceleration.

The .ftproj project format is unchanged. The release targets Windows 10
(1809 or later) and Windows 11 x64 with installer and portable ZIP, subject
to clean-runner verification. Linux users can build from source; macOS and
Linux prebuilt installers are not supplied. Windows binaries are unsigned.
No WinGet store availability is implied.

See the [faster export guide](../user-guide/faster-export.md).
