## Manual testing (not performed in this release workflow)

The [manual editor smoke-test checklist](../development/v1.3.0-smoke-checks.md)
remains a separate list of real-user scenarios. The automated CI, GUI tests
and clean-host installer checks do **not** establish a complete human-tested
creative-editing workflow on physical hardware. No manual pass evidence was
recorded here.

## Scope boundary

Only changes merged into the release tag are shipped. Open proposals such
as Zoom to Selection (PR #70), preview-frame PNG export (PR #27), and
further timeline bulk operations are *not* included merely because their
feature branches exist. The `.ftproj` project format remains unchanged.

See the [stable release notes](v1.3.0.md) for verified shipped features and
known limitations.
