# FrameTrellis 1.3.0 — DRAFT RELEASE NOTES (NOT RELEASED)

> **Development document only.** FrameTrellis 1.3.0 is **not published**.
> The latest downloadable stable release is **1.2.2**. These notes describe
> changes integrated on the development `main` branch as of 25 October 2026.
> Review and update them against the eventual release commit before publication.
> Do not use this draft as a GitHub release description until it has been verified
> and the word **DRAFT** has been removed by explicit release approval.

## Reliability and source safety

- Prevent saving a FrameTrellis project over a media file referenced by that project
  (PR #23). Validate clip and track timecode boundaries more defensively (PR #22).
- Reject duplicate media file identities, including alternate/canonical path spellings,
  during import, relink and project loading (PR #24).
- Detect edits to source files even when their sizes have not changed, helping editors
  notice out-of-date media references (PR #25).
- Prevent the standalone render helper from replacing the project document it loaded,
  tighten its line-based cancellation protocol, and add read-only
  `--inspect-project --project FILE` diagnostics (PR #68).
- Serialize MLT profile creation to avoid a sanitizer-observed concurrent initialization
  crash; include a multithreaded regression test (PR #63).
- Protect clip fade validation against signed overflow (PR #30).
- Bound helper protocol messages (PR #19); keep Unicode destination-path export regression
  tests (PR #17).

## Documentation

- Improve the documentation website with a guide filter, on-page section navigation
  and copyable code blocks, including tests and a maintainer guide (PR #69).

## Everyday editing and navigation

- Filter the media bin by text and media category to find source footage,
  audio and images more quickly in larger projects (PR #16).
- Use **Playback → Go to Timecode** (`Ctrl+G`) to navigate to a
  frame-accurate position in the sequence (PR #26).

## Project inspection

Use the development-branch `frametrellis-render` executable to inspect an existing
project without starting an export:

```sh
frametrellis-render --inspect-project --project my-edit.ftproj
```

The `@ft` JSON event reports clip, track, media, referenced/unused and missing-file counts
without including the media's local source paths. This command is not available in the
published v1.2.2 download.
