# FrameTrellis 1.3.0 — Safer editing, media discovery and export diagnostics

FrameTrellis 1.3.0 improves reliability when editing and exporting existing
projects, adds faster media discovery and precise timecode navigation, and
extends the documentation site. The project remains local-first: no account,
cloud upload, telemetry or subscription is needed.

## What's new

### Protect projects and footage

- Guard against saving project documents over media files referenced by the
  same edit; reject render output destinations that would overwrite the open
  project, even when the project has a video filename extension.
- Reject duplicate source-media identities at import, relink and project load,
  including alternate paths to the same canonical file.
- Detect externally modified media even when the file's size has not changed.
- Harden timeline and source-clip boundary checks, fade-duration validation
  and free-range searches against invalid or overflowing frame arithmetic.
- Serialize MLT profile initialization to address a concurrency failure found
  with AddressSanitizer.

### Media and editing workflow

- Search the media bin by filename or path and filter by video, audio or
  image type without changing the underlying project media.
- Open **Playback → Go to Timecode** (Ctrl+G) to navigate to a specific
  sequence frame with validated SMPTE timecode input.

### More robust headless rendering

- Use `frametrellis-render --inspect-project --project FILE` to inspect
  track counts, clip counts, referenced and unused media, missing assets
  and sequence length without launching a render or revealing source paths.
- Parse cancellation as an exact line command and bound helper protocol
  messages; reject destinations that overlap the loaded project.
- Add regression coverage for Unicode export destinations, concurrent
  engine initialization and media/timeline validity.

### Documentation

- Filter guides in the website sidebar, use section navigation and copy
  code examples directly; accessibility and navigation tests are included.

## Compatibility and known limitations

- The existing `.ftproj` project file format is unchanged.
- Official downloads: **Windows x64** installer and portable ZIP,
  verified by automated clean-runner checks, including Windows 11 ARM64
  through x64 emulation. Linux can be built from source; there is no
  Linux binary distribution or supported macOS package yet.
- Windows packages are **not code-signed**. Check the included SHA-256
  hashes before running the installer.
- Export remains MP4 with H.264 video and AAC audio. MLT parallel-frame
  rendering stays disabled because of earlier audio-corruption issues;
  neither GPU acceleration nor lossless stream-copy joining is promised.
- Titles are PNG overlays rather than editable text layers; advanced
  keyframes, subtitle editing, proxies and more export formats are planned.
- WinGet availability is **not** implied by this release.
