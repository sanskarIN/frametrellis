# FrameTrellis 1.3.1 — Maintenance and media-bin interaction fixes

FrameTrellis 1.3.1 is a **stability-focused patch** based on the published
[v1.3.0 source](https://github.com/sanskarIN/frametrellis/releases/tag/v1.3.0).
It intentionally **does not include** experimental development on `main`,
including subtitle, opacity/volume/transform keyframes, newer project formats
or open feature PRs.

## Fixed

- Fix a QML delegate lookup that could log `ReferenceError: grid is not defined`
  when selecting or double-clicking a media-bin tile. The tile now resolves
  its owning GridView using the attached view property.
- When a missing/offline media tile has keyboard focus, **Enter** now requests
  the relink workflow instead of attempting to append an unavailable source.
- Add a real GUI regression assertion that rejects QML warnings from media-bin
  tile interactions. The maintenance branch runs the normal Linux, sanitizer,
  formatting, packaging and Windows clean-host verification workflows.

## Compatibility

- Project document format remains unchanged from 1.3.0; no migrations are
  introduced by this patch.
- MP4 (H.264/AAC) export, Qt/MLT dependencies and the editing feature set
  are unchanged. This is not a new feature release.
- Official built artifacts are Windows x64 installer and portable ZIP;
  Linux can be built from source. No macOS package or WinGet listing is claimed.
- Windows artifacts are **not code-signed**. Verify `SHA256SUMS.txt` against
  the downloaded files before installation.

## Verification and publishing

The v1.3.1 maintenance tag is created only after the exact release commit
passes both repository **CI** and **Windows packages** workflows. The release
workflow subsequently rebuilds the package, verifies it on clean Windows
Server 2022, Windows Server 2025 and Windows 11 ARM64 runners, collects third-party
source archives, generates SHA-256 checksums and publishes the downloads.
Automated checks are not a substitute for manual testing on physical hardware.
