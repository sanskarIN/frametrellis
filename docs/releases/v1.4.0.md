# FrameTrellis 1.4.0 — Timeline editing, keyframes and subtitle workflows

FrameTrellis 1.4.0 is a feature release of the local-first C++20 / Qt / MLT
desktop video editor. It integrates editing and interchange features developed
after the narrow v1.3.1 maintenance release. Editing, preview and export remain
local: no account, remote processing or telemetry is required.

## What's new

### Multi-track editing and precision navigation

- Select clips under the playhead, before or after it, across a track, by a
  shared media source, or by overlap/containment in a selected time range.
- Align selected clips' start/end to the playhead, duplicate multi-track
  selections there, and retain inter-clip timing with atomic Undo/Redo and
  locked-track/collision checks.
- Insert or remove empty time across tracks, set an exact frame-count gap,
  trim clip edges to the playhead, slip sources and roll adjacent edits where
  source handles permit.
- Navigate selected clip edges and the selection's start, last visible frame
  or midpoint. Zoom to selected clips and center the timeline on the playhead.
- Copy the outer multi-track selection's exact SMPTE start, exclusive end,
  final visible frame and duration to the clipboard without changing the edit.
- Jump five or ten seconds backward/forward with keyboard shortcuts using
  fractional project-frame rates; navigate to the earlier middle visible
  frame of the whole sequence without modifying the project or Undo history.
- Reorder or duplicate tracks, and lock/unlock all tracks in one undoable edit.
- Place persistent timeline review markers and navigate between them.

### Video, sound and animated effects

- Edit source-anchored **volume** keyframes in decibels and **opacity**
  keyframes using timeline and inspector controls.
- Animate image/video **position, scale and rotation** with transform
  keyframes and direct monitor controls.
- Set brightness, contrast, saturation, opacity, fades and gain, including
  selected-clip batch presets and precise numeric picture adjustments.
- Preview and MP4 export share the implemented automation and compositing
  paths, with regression tests inspecting representative image/audio results.

### Subtitles, review and interchange

- Edit a sequence subtitle track, import/export UTF-8 SRT, export a WebVTT
  sidecar, shift all cues' timestamps atomically and export a timestamped
  Unicode TXT transcript. Caption burn-in is optional.
- Copy timeline markers as video-description chapters or HTML5 WebVTT
  chapter cues. Export cuts-only CMX3600 EDL picture decisions (complex
  transitions and effects cannot be reconstructed from this file).
- Export UTF-8 clip lists and media inventories as formula-safe CSV;
  export a local media audit as JSON.
- Save a protected PNG snapshot of the current preview; import folders
  asynchronously, filter used/unused/changed media, and append source excerpts.

### MP4 delivery presets

- Creator upload profiles up to 1080p, 1440p and 4K, avoiding upscaling.
- Low-bandwidth review profile up to 480p, alongside 720p draft, quick
  export and turbo preview profiles.
- H.264 video and AAC audio in MP4, with adjustable CRF, encoder speed and
  audio bitrate. A destination replaces an existing file only after a
  successful, validated render.

### Project integrity and recovery

- Reject blank or whitespace-only imported and replacement media paths.
- Reject imported/relinked media names longer than 512 characters and source
  paths longer than 4,096 characters, matching the .ftproj reader's limits,
  so newly saved projects remain compatible with their own reader.
- Omit optional project-folder relocation hints that exceed the supported
  path length instead of writing a project file that cannot be reopened;
  preserve the original absolute media path without truncation.
- Validate project names, inserted/restored track names, and duplicate clip,
  track or transition IDs before accepting invalid timeline state.
- Check project validity before a Save / Save As writes to its destination.
  A failed validation leaves the existing project file intact.

## Project compatibility — read before upgrading

**Back up existing projects before opening or saving them in 1.4.0.**
Newer .ftproj project document formats are written only when needed:
v2 for markers; v3 for volume keyframes; v4 for opacity keyframes;
v5 for transform keyframes; and v6 for subtitles/caption styling.
The current reader accepts v1–v6. A basic project may save using an
earlier compatible format, but the v1.3.1 stable editor may refuse documents
requiring newer formats. Do not overwrite the only copy of a working edit.

## Availability and known limitations

- Official packages: **Windows x64 installer and portable ZIP**. Windows
  Server 2022/2025 and Windows 11 ARM64 (x64 emulation) are clean-host
  verification targets. Linux builds from source. No macOS package, AppImage,
  Flatpak or WinGet availability is claimed.
- The Windows binaries are **not code-signed**; check published SHA-256
  checksums and the bundled third-party source/SBOM materials.
- No proxies, hardware encoding, live collaboration, full advanced colour
  grading or lossless stream-copy joining is claimed.
- Export remains H.264/AAC MP4; switchable embedded text subtitle streams
  are not produced. Titles are PNG overlays, not editable native text layers.
- Cuts-only EDL interchange is intentionally limited and requires third-party
  validation with the intended target application.

## Verification and release controls

Before publication, verify the **exact integrated release commit**: Linux GCC
(warnings as errors), CTest unit/integration/GUI, sanitizers, Windows MSYS2,
formatting, scripts, website, renderer container and Windows clean-host
installer/portable verification. The release workflow rebuilds artifacts,
generates the SPDX bill of materials and corresponding third-party source
archive and publishes SHA-256 checksums only after its verification gates.

Automated tests do not establish actual physical GPU/audio editing results.
See the [v1.4.0 preflight checklist](v1.4.0-preflight.md) and
[manual acceptance matrix](../testing/v1.4-integrated-editing-acceptance.md).
This document alone does not assert that the release has been published.
