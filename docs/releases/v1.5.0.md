# FrameTrellis 1.5.0 — Featured Release

FrameTrellis is a free, local-first, open-source desktop video editor built
with C++20, Qt 6, MLT and FFmpeg. Version 1.5.0 expands precision editing,
export control, media recovery and audio finishing while strengthening
the Windows desktop and multi-platform source-build workflows.

**Downloadable release assets in this distribution: Windows x64 installer and
portable ZIP.** Linux x86_64 and macOS 15+ (Apple Silicon and Intel) are
**supported through source builds**, not standalone production installers.

## New in 1.5.0

### Source Monitor and precision editing

- Separate Source and Program views, with frame-accurate source In/Out marking.
- Insert selected media ranges into compatible destination tracks, keeping
  matching picture and sound excerpts together as a single undoable edit.
- Replace selected clips using compatible source ranges while preserving
  sequence timing and safe clip properties.
- Ripple insertion and timeline-gap operations can move affected clips,
  review markers and eligible subtitles together; ambiguous or locked
  changes are rejected instead of silently desynchronizing the edit.
- Fit the whole timeline in the editor with **Ctrl+0**.

### Flexible video exports

- Select a video export frame rate independently of the project timebase,
  including common integer rates, NTSC (30000/1001) and valid custom rational
  values. Project timing and audio pitch/speed are preserved.
- Export a selected timeline range and control output frame counts precisely.
- Sequential delivery presets, including Creator 1440p and Creator 4K,
  with no-upscale protection and safer destination naming.
- Custom output width with proportional even-pixel height.
- Improved render-helper isolation, cancellation and bounded diagnostic
  handling; failures avoid overwriting earlier successful exports.
- Stronger MP4 validation, including checking for missing, unwanted or
  malformed audio where applicable.

### Media management and project recovery

- Find and relink missing files in batches using bounded background scanning.
  Ambiguous name matches and incompatible replacements are skipped.
- Apply compatible relinks as a single undoable project edit without changing
  the source media.
- Change a project's display name without changing the saved `.ftproj`
  filename, including Unicode-safe validation.
- Fresh recovery snapshots before export and improvements to repeated
  interruption recovery.

### Audio, subtitles and timeline workflow

- Per-clip stereo balance, including left, centre and right presets,
  independently of volume and fades.
- More subtitle editing operations: WebVTT plain-text import, splitting,
  merging, timing stretch and alignment to sequence frames, with validation
  and Undo/Redo support.
- Additional Program preview looping, timeline navigation and media
  inspection controls.

### Stability, diagnostics and verification

- Windows package dependency and startup validation improvements.
- Hardened preview and thumbnail lifetime/allocation paths.
- More informative export cancellation and failure diagnostics, including
  optional local-only Windows crash and repeated-export diagnostic tools.
- Expanded automated checks for package structure, audio/video export,
  project compatibility and Windows, Linux and macOS source builds.

## Platform availability

| Platform | Distribution |
| --- | --- |
| Windows 11 / Windows 10 1809+ x64 | Installer and portable ZIP |
| Windows 11 ARM64 | Windows x64 build via emulation; see startup limitation below |
| Linux x86_64 | Build from source; requires a compatible Qt/MLT/FFmpeg/SDL environment |
| macOS 15+ Apple Silicon (arm64) | Build from source with Homebrew dependencies |
| macOS 15+ Intel (x86_64) | Build from source with Homebrew dependencies |

**There are no officially distributed Linux AppImages or Apple-notarized macOS
DMGs in the five-file source-build distribution.** Experimental development
packages are not equivalent to stable downloadable installers.

See the [building guide](../development/building.md) for native toolchain,
dependency, build and test instructions.

## Verify Windows downloads

The published release is expected to contain **exactly five** assets:
`FrameTrellis-1.5.0-windows-x64-setup.exe`,
`FrameTrellis-1.5.0-windows-x64.zip`,
`FrameTrellis-1.5.0-windows-x64.spdx.json`,
`FrameTrellis-1.5.0-windows-x64-third-party-sources.tar`
and `SHA256SUMS.txt`.

Download the matching `SHA256SUMS.txt` and check file hashes before running
the unsigned Windows binaries. The release must not be considered complete
unless every asset is attached and verified.

## Upgrade and known limitations

- **Back up your projects before upgrading.** This version may write project
  format v7 for features such as non-centre stereo balance; older FrameTrellis
  releases cannot necessarily open newer `.ftproj` files.
- Windows packages are not code-signed; verify the published SHA-256 checksums.
- Earlier native Windows [long-export process failures (#175)](https://github.com/sanskarIN/frametrellis/issues/175)
  have mitigations and additional diagnostics, but no confirmed root-cause
  resolution. An [intermittent Windows 11 ARM x64-emulation startup
  failure (#185)](https://github.com/sanskarIN/frametrellis/issues/185)
  likewise remains under investigation; repeated clean CI runs are
  non-reproduction evidence rather than a proven fix.
- Hardware-accelerated encoding, proxy editing, and switchable embedded MP4
  subtitle tracks are not included.
- No official standalone Linux or macOS release packages are included.
