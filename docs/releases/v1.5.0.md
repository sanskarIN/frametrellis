**Candidate release notes.** The latest publicly available stable download remains

## Proposed improvements since v1.4.0

### Source Monitor and precision editing

- Separate Source and Program viewing, frame-accurate source In/Out marks and
  non-destructive append of a selected source range.
- Choose compatible destination tracks, place a marked range at the Program
  playhead, and place matching picture/audio excerpts atomically on separate
  tracks when an imported source carries both streams.
- Replace one selected clip from a matching source excerpt while retaining its
  timeline timing and preserving safe scalar properties.
- Ripple-insert marked excerpts while shifting later clips, markers and
  eligible subtitle cues together as one undoable operation; reject unsafe
  mid-clip, locked-track, transition and subtitle-spanning cases.

### Export, editing safety and Windows diagnostics

- Select output MP4 FPS separately from the project timebase, including common
  integer/NTSC rates and custom rational frame rates. Preserve sequence timing
  and audio speed; verify output duration, dimensions and exact frame rate.
- Save fresh recovery data before export, pause competing preview playback, and
  keep the renderer isolated in a subprocess.
- Bound helper stdout/stderr processing and detect malformed progress frame
  counts without unsafe numeric conversion.
- Preserve prior successful exports on helper failures or cancellations; isolate
  and clean up only the job-owned temporary file after the renderer exits.
- Honor cancellation during renderer startup and expensive graph/encoder setup.
- Add optional, locally controlled Windows minidump configuration for native
  crash diagnostics (not enabled automatically and never uploaded).
- Harden Qt Quick preview and thumbnail allocation, with repeated Windows ARM
  GUI launch diagnostics. These are mitigations, **not a verified root-cause fix**
  for the reported native crashes.

### Timeline workflow

- Loop Program preview without modifying the project or export output.
- Find a media asset's timeline uses, inspect local source metadata and sort
  imported media by duration or usage.

## Known limitations and unresolved release blockers

- [Export native failures #175](https://github.com/sanskarIN/frametrellis/issues/175)
  have no confirmed faulting native call stack or identified root cause.
  An editor access violation and a renderer in-page error must be investigated
  separately. Passing short automated exports cannot establish long-export
  reliability on physical Windows hardware.
- [Intermittent Windows ARM GUI crash #185](https://github.com/sanskarIN/frametrellis/issues/185)
  needs a cause-based resolution or explicitly documented, evidence-backed
  release decision. Passing repeated CI launches is not proof of a fix.
- No hardware encoder, proxy workflow, Linux/macOS official package or
  switchable MP4 subtitle stream is promised by this candidate.
- The project reader supports formats v1–v6; save copies before testing
  newer editor builds. Some older stable builds cannot read newer features.
