# FrameTrellis 1.5.1 — DRAFT, NOT RELEASED

> **Internal candidate notes only.** The project remains at CMake version 1.5.0.
> This document must be reviewed, edited and marked final before any v1.5.1
> release preparation can succeed. No v1.5.1 tag or published release exists
> as a result of these notes.

## Candidate maintenance changes (subject to exact-tag verification)

- Safer verification of encoded media duration when probes return invalid or
  extreme 64-bit microsecond values ([PR #296](https://github.com/sanskarIN/frametrellis/pull/296)).
- Bounded APT package mirror retries on Linux CI runners without suppressing
  real dependency failures ([PR #298](https://github.com/sanskarIN/frametrellis/pull/298)).
- Exact integer playback transport and saturating frame jumps for large
  timelines ([PR #299](https://github.com/sanskarIN/frametrellis/pull/299)).
- Additional post-v1.5.0 maintenance changes must be reviewed and verified
  against the final source commit before being listed as shipped.

## Candidate distribution scope — not yet approved

The proposed scope follows the published v1.5.0 option: an unsigned Windows
x64 installer and portable ZIP, corresponding third-party sources, SPDX
bill of materials and SHA256SUMS, plus Linux x86_64 and macOS 15+ source
build support. It does **not** claim official AppImages or notarized DMGs.
