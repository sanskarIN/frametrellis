# FrameTrellis 1.5.1 — Maintenance Release

FrameTrellis is a free, local-first video editor built with C++20, Qt 6,
MLT and FFmpeg. Version 1.5.1 is a maintenance update to 1.5.0, focused on
safer native rendering, predictable export controls and handling malformed
or extreme media inputs. It does not replace the 1.5.0 feature set.

## Improvements since 1.5.0

### Export and rendering stability

- Fixed the Windows-visible **Export video** dialog layout: presets and output
  paths retain readable space; quality, encoder speed, audio and batch controls
  remain aligned when changing the timeline range. Smaller windows scroll the
  settings while keeping the Export button accessible
  ([#304](https://github.com/sanskarIN/frametrellis/pull/304)).
- The render helper's progress messages can no longer change the expected
  output frame count, go backward or duplicate a valid start event
  ([#302](https://github.com/sanskarIN/frametrellis/pull/302)).
- Reject malformed project dimensions before scaling for export
  ([#303](https://github.com/sanskarIN/frametrellis/pull/303)).
- Verify MP4 encoded duration without overflowing signed 64-bit microseconds
  ([#296](https://github.com/sanskarIN/frametrellis/pull/296)).
- Validate malformed quality settings and unexpected export completion paths;
  reject incomplete or inconsistent renderer success claims.

### Playback and media safety

- Preserve exact integer playhead transport and saturate large frame jumps,
  avoiding loss of precision and signed arithmetic overflow
  ([#299](https://github.com/sanskarIN/frametrellis/pull/299)).
- Strengthen the preview decoder's allocation caps, seek-range checks and
  non-finite volume handling.
- Reject invalid media durations, excessive audio sample rates and unsafe
  waveform/thumbnail ranges before they can reach native decoders.
- Additional UI validation for timecodes, clip attributes and extreme input
  values; improved source-monitor initialization safety.

### Build and verification

- Retry transient Ubuntu package-mirror errors within bounded limits while
  preserving CI failure on a permanent dependency error
  ([#298](https://github.com/sanskarIN/frametrellis/pull/298)).
- Extend automated GUI, unit, sanitizers, Windows package and native
  Linux/macOS source-build regression tests. Automated passing tests do
  not substitute for testing actual long videos on a Windows machine.

## Supported platforms and downloads

The intended **five-file distribution** includes a Windows 10 (1809+) /
Windows 11 x64 installer, a portable ZIP, an SPDX 2.3 bill of materials,
corresponding third-party sources and `SHA256SUMS.txt`. Windows packages
are unsigned; verify file checksums before use. A Windows 11 ARM device may
run the Windows x64 build through emulation, subject to the limitation below.

Linux x86_64 and macOS 15+ (Apple Silicon and Intel) remain supported by
**source builds** with the required Qt/MLT/FFmpeg toolchain. Experimental
AppImages and macOS disk images are *not* official production release
downloads. Follow the
[build guide](https://github.com/sanskarIN/frametrellis/blob/main/docs/development/building.md).

## Upgrade advice and known limitations

Back up important `.ftproj` projects before upgrading; a newer saved project
may not open correctly in an older version. Project-format compatibility is
subject to pre-release smoke tests, and source media is never converted as
part of installation.

There is **no confirmed root-cause fix** for earlier Windows long-MP4-export
process crashes ([#175](https://github.com/sanskarIN/frametrellis/issues/175))
or the intermittent Windows 11 ARM x64-emulation startup failure
([#185](https://github.com/sanskarIN/frametrellis/issues/185)).
The reported failures are separate; additional crash isolation and automated
non-reproduction do not establish that they can never recur. Please preserve
a recovery copy and report reproducible failures with redacted diagnostics.
Hardware-accelerated export, proxy editing and switchable embedded MP4
subtitle tracks are still outside this release.
