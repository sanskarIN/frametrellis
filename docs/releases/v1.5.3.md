# FrameTrellis 1.5.3 — Maintenance Release

This maintenance version focuses on more reliable MP4 exports, bounded
subtitle decoding, and stricter export settings validation.

## Improvements and fixes

- Bound WebVTT entity lookahead and decoded subtitle length to avoid excessive
  work on malformed subtitle input ([#341](https://github.com/sanskarIN/frametrellis/pull/341)).
- Reject unknown export presets and non-boolean audio/upscaling options before
  starting a render or batch ([#346](https://github.com/sanskarIN/frametrellis/pull/346)).
- Reserve temporary MP4 outputs exclusively and reject unsafe publication
  destinations, symbolic links and missing or empty partial outputs
  ([#350](https://github.com/sanskarIN/frametrellis/pull/350)).
- Preserve existing output on failure or cancellation; require a matching
  helper reservation acknowledgement before parent-side partial cleanup.
  An interruption before acknowledgement can leave a partial file for
  manual inspection rather than deleting an unclaimed path.
- Improve export preparation, finalization and quiet-progress diagnostics,
  report encoder/canvas/FPS/audio context when output is empty, and validate
  the initial seek. Repeated progress events no longer reset the quiet timer.
- Extend regression coverage for export options, cancellation/retry,
  destination preservation and occupied or unclaimed temporary paths.

## Distribution and known limitations

The distribution scope is unsigned Windows x64 installer and portable ZIP,
SPDX SBOM, corresponding third-party sources and SHA256SUMS.txt. Linux and
macOS remain source builds; experimental packages are not production installers.
The intermittent native encoder and Windows ARM startup failures are not
claimed resolved solely on the basis of hosted tests.
Portable-project, checkpoint and timeline-review features are outside this
maintenance scope.

See [release preflight](v1.5.3-preflight.md) for qualification requirements.
