# FrameTrellis 1.5.3 — Maintenance Release

> Candidate notes — NOT PUBLISHED. The intended date is 26 November 2026.
> This is not a release approval or a promise of completed native QA.

## Accepted changes since v1.5.2

- Bound WebVTT entity lookahead and decoded subtitle length to avoid excessive
  work on malformed subtitle input ([#341](https://github.com/sanskarIN/frametrellis/pull/341)).
- Reject unknown export presets and non-boolean audio/upscaling options before
  starting the render or batch ([#346](https://github.com/sanskarIN/frametrellis/pull/346)).

## Proposed change pending integration and qualification

[#350](https://github.com/sanskarIN/frametrellis/pull/350) protects temporary MP4
output reservation and publication, improves preparation/finalization/stalled
progress diagnostics, and adds immediate cancellation/retry regression coverage.
The proposed helper/editor reservation acknowledgement also prevents cleanup of
unclaimed temporary files after a collision or mismatched token.
Include these changes in final release notes only after merging and qualifying
one frozen main revision. The intermittent native encoder failure is not proven
resolved.

## Distribution scope

The proposed scope is unsigned Windows x64 installer and portable ZIP, SPDX
SBOM, corresponding third-party sources and SHA256SUMS.txt. Linux and macOS
remain source builds; experimental packages are not production installers.
The new portable-project, checkpoint and timeline-review features are outside
this maintenance scope.

See [candidate preflight](v1.5.3-preflight.md) before any owner publication.
