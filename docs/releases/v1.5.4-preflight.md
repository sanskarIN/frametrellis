# FrameTrellis 1.5.4 qualification checklist

Target: 28 November 2026. Latest published stable:
[v1.5.3](https://github.com/sanskarIN/frametrellis/releases/tag/v1.5.3).
This document does not authorize publication.

- Freeze one exact protected-main SHA after integrating reviewed changes.
- Verify the CMake version and release notes; ensure there is no existing tag
  or release for v1.5.4.
- Require successful CI, desktop-platform, Windows package and website push
  runs on that exact SHA. Verify native tests and clean-host package checks.
- Test project round-trip, rejected invalid saves preserving prior contents,
  thumbnail generation/cache recovery, unusual preview dimensions, save/reopen,
  startup, long MP4 export and cancel/retry on physical Windows.
- Use a successful exact-SHA Prepare manual release run. Extract the unique
  unexpired manual-release-assets artifact. Run:

  ```bash
  python3 packaging/verify_release_assets.py --version 1.5.4 --directory release
  (cd release && sha256sum --check SHA256SUMS.txt)
  ```

- Record exact SHA, run IDs and physical outcomes; request a separate owner
  decision. No development request or green PR is publication permission.
- After that decision the owner creates the stable release and can attach
  the verified five files manually, or use the exact version-specific
  owner-gated attachment workflow. Do not mix manual and automatic upload.
- Verify public asset inventory and SHA-256 against the candidate before
  advertising downloads; preserve all prior tags and assets.
