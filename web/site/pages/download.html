Build from source

FrameTrellis needs a C++20 compiler, CMake 3.21 or newer, Qt 6.5 or newer, MLT 7 with its FFmpeg module, and optionally SDL 2 for audio playback. The building guide has the complete instructions.

Windows 11 (MSYS2 UCRT64 shell)

pacman -S --needed mingw-w64-ucrt-x86_64-{cc,cmake,ninja,pkgconf,qt6-base,qt6-declarative,qt6-svg,mlt,ffmpeg,SDL2}
git clone https://github.com/sanskarIN/frametrellis.git
cd frametrellis
cmake --preset windows-msys2
cmake --build --preset windows-msys2
ctest --preset windows-msys2

Ubuntu 24.04

sudo apt install build-essential cmake ninja-build pkg-config git \
  libavformat-dev libavcodec-dev libavutil-dev libavfilter-dev libavdevice-dev \
  libswscale-dev libswresample-dev libsdl2-dev libgl1-mesa-dev libxkbcommon-x11-0 libxcb-cursor0
pipx install aqtinstall                      # Ubuntu 24.04's Qt 6.4 is too old
aqt install-qt linux desktop 6.8.3 linux_gcc_64 -O "$HOME/Qt"
git clone https://github.com/sanskarIN/frametrellis.git && cd frametrellis
scripts/build-mlt.sh v7.22.0 "$HOME/.local/mlt"   # the MLT modules FrameTrellis needs
cmake --preset linux -DCMAKE_PREFIX_PATH="$HOME/Qt/6.8.3/gcc_64;$HOME/.local/mlt"
cmake --build --preset linux
ctest --preset linux
./build/linux/bin/frametrellis

Verifying a download

Every release lists the SHA-256 checksum of each file in SHA256SUMS.txt. On Windows, compare it with:

Get-FileHash .\FrameTrellis-<version>-windows-x64-setup.exe -Algorithm SHA256

On Linux and macOS, use sha256sum -c SHA256SUMS.txt.
